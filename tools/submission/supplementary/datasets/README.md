# Datasets

This project uses **no external dataset**.

Every experiment's input is generated by the workload generator (`code/workload/wlgen.c`) from the experiment configuration (`code/harness/configs/*.json`, with the workload mixes in `mixes.json`) and a random seed. The same seed always produces the same request arrival times and work amounts, so the inputs can be regenerated exactly; nothing needs to be downloaded or preprocessed.

The data **measured** in the reported experiments (golden run `20261106-174432`, 734 runs) is included, packed, in `code/results/raw/` as `<batch>_20261106-174432.tar.zst` files with SHA-256 checksums (`main` is split into two parts). `make reproduce` in `code/` verifies, unpacks and analyses it. The per-batch summaries derived from it are in `code/results/summary/` and copied to `supplementary/experimental_results/summary/`.
